# Conference Planner
This web platform is aimed towards Youth for Christ (YFC) leaders preparing for annual national conferences.

This platform is built with a React + Vite frontend, Express.js backend for API endpoints, databases written in mySQL that is hosted in Cloud SQL (Google Cloud) and Cloud Storage (Google Cloud), user authentication built with Firebase, and deployed using App Engine (Google Cloud).

## Current Features
- **Log In**
- **Task List** - Add, edit, delete tasks, assign members and committees, attach files and links, mark tasks complete
