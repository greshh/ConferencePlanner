# Conference Planner
This web platform is aimed towards Youth for Christ (YFC) leaders preparing for annual national conferences.

This platform is built with a React + Vite frontend, Express.js and Prisma backend for CRUD operations and integrating the database, and mySQL and Cloud Storage (Google Cloud) databases.

## Set Up
For backend:
1. `cd backend`
2. `npm start`

For frontend:
1. `cd frontend`
2. `npm run dev`
